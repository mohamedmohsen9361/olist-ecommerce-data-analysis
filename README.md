# 🛒 E-Commerce Operations & Performance Dashboard

An end-to-end Power BI & Python analytics project transforming raw e-commerce sales, operational, and financial data into actionable business insights. This project tracks overall business performance, evaluates YoY financial metrics, and isolates seller SLA logistics bottlenecks.

## 🛠️ Tech Stack & Tools
* **Data Cleaning & Pipeline:** Python (`Pandas`, `NumPy`)
* **Data Modeling & DAX:** Microsoft Power BI
* **Data Visualization:** Multi-page Interactive Power BI Dashboard

---

## Key Highlights

* **Data Engineering Pipeline:** Built a structured Python cleaning and transformation pipeline (`Pandas`/`NumPy`) to clean raw datasets, handle missing values, and enforce strict data typing prior to modeling.
* **Advanced Analytics:** Implemented advanced time-intelligence DAX measures (YoY, SPLY) alongside custom SLA breach formulas to measure seller fulfillment speeds and dispatch efficiency.
* **Interactive Reporting Architecture:** Designed an executive multi-page dashboard structure tailored for high-level management and operations teams.

---

## 📊 Dashboard Modules

* **Executive Performance Overview:** High-level executive KPIs covering total revenue, order volume, average order value (AOV), and overall fulfillment rates.
* **Time Intelligence & Trends:** Comparative YoY analytics (Same Period Last Year) tracking seasonal revenue surges, monthly order frequency, and customer growth trends over time.
* **Customer & Seller Logistics Analysis:** Geographic density heatmaps at the state level, combined with seller performance metrics, repeat customer rates, and SLA breach tracking.

---

## 🧩 Challenges & Solutions

* **Challenge:** Dealing with a complex multi-table relational schema, missing values in delivery timestamps, and cross-filtering conflicts between customer and seller geographical contexts.
* **Solution:** Programmatically cleaned and aligned data using Python scripts prior to import, then established an optimized star-schema model in Power BI with context-aware DAX measures for accurate multi-dimensional filtering.
